# 🚀 Reto de Programación #1: Sensor de Vuelo - Cohete Suborbital

¡Bienvenido al repositorio del **Reto #1**! Este proyecto contiene la solución de programación para la situación propuesta acerca del procesamiento de datos del **sensor de vuelo de un cohete suborbital**. 

## 📋 Descripción del Reto
El sistema simula el vuelo de un cohete para determinar las multiples variables que se pueden relacionar con el a lo largo de un vuelo, adicionalmente marca el punto de apogeo máximo y el estado del cohete respecto a su temperatura. 

### Conceptos Clave
* **Adquisición de Datos:** Lectura de altitud (barómetro), aceleración y temperatura mediante lineas de codigo de numeros aleatorios.
* **Detección del Apogeo:** Algoritmo optimizado para identificar el punto más alto del vuelo y activar la secuencia de eyección de paracaídas.
